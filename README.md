# CloudScale: Cloud Network Infrastructure
## A Case Study on Cost Optimization and Scalability

Please refer to [`cloudscale/README.md`](cloudscale/README.md) for the full detailed documentation.

### Quick Start (Windows PowerShell)

```powershell
# 1. Install dependencies
python -m pip install -r requirements.txt

# 2. Run automated tests (All 20 tests pass)
python -m pytest -v cloudscale/tests

# 3. Launch the presentation dashboard
python -m streamlit run app.py
```
Open **`http://localhost:8501`** in your browser to interact with the dashboard.
